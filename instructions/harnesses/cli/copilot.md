# CLI Harness: Copilot

- Follow repository custom instructions and path-specific instructions when present.
- Keep instructions concise and actionable; long generic guidance should stay in MOD source docs, not ad-hoc prompts.
- Break complex work into smaller verifiable tasks and include acceptance criteria.
- Prefer build/test/validate commands that can run in the working environment before proposing completion.
- For review-style work, lead with concrete findings and evidence before summaries.
